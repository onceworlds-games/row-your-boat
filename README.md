# Row Your Boat

Row on the beat down a dream of a river. Fastest boat wins.

A 3D rhythm race for up to six boats: silver ripples roll down the river onto your oars in time with the song, and every
stroke on the beat lights a lantern and speeds you up. Tap the side you want to go. Eight dreams (a bedroom, teacups, a
library, clockwork, the sea of stars...), races with friends or rival rowers, and The Dream, a solo run of all eight.

Play: https://onceworlds.com/play/row-your-boat

## Run it

```sh
npm install
npm test        # the race rules, the judge, the courses, the rowers and the room, in node
npm run build   # the game in dist/
```

Built with three.js and Vite. The design is in [DESIGN.md](DESIGN.md).
