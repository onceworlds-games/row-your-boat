# Row Your Boat

Row to the song down a dreaming river: pull on the gold beats, tap the merrily droplets, gather moonblooms. Race friends
or rowers, earn new boats, row tonight's stream.

A 3D rhythm race for up to six boats on a moonlit river that mirrors the sky. Ripples roll down the water onto your oars
in time with "Row, Row, Row Your Boat": every stroke on the beat lights a lantern and speeds you up, and you tap the side
you want to go. The song is the chart: both oars on the gold beats for a pull, the droplets between the beats in the
merrily bar for a rush, and lines of glowing moonblooms to steer through. Eight dreams (a bedroom, teacups, a staircase,
clouds, a library, clockwork, the sea of stars, morning), races with friends or rival rowers, and The Dream, a solo run
of all eight with ghosts and stars.

Every run pays XP and moonblooms: thirty levels with a reward on each (a canoe, a paper boat, a swan, a teacup, a walnut
shell, a bathtub), the Boathouse for hats, lanterns, trims and wake trails, Tonight's Dream (one stream a night with a
twist, the same for everyone), three wishes a night and a moon calendar for the nights you row.

Play: https://onceworlds.com/play/row-your-boat

## Run it

```sh
npm install
npm test        # the race rules, the judge and the chart, the courses, the rowers, progression and the room, in node
npm run build   # the game in dist/
```

Built with three.js and Vite. The design is in [DESIGN.md](DESIGN.md).
